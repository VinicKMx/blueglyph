# Blueglyph

`blueglyph` is an open-source BLE debugger and sniffer for nRF52840-based capture hardware.
The project goal is to turn radio packets, advertisements, connections, ATT/GATT traffic, and Link Layer events into reproducible captures and human-readable diagnostics.

> Raw packets when you need them. Answers when you do not.
